There are 3 types of variables. 1. var: It is global scoped variable. It can ve reclared and redefined. It is hoisted, which means it can be used before its declaration. 2.let: It is block scoped variable. It cannot be reclared in the same scope but it can be redefined. It is not hoisted, which means it cannot be used before its declaration. 3.const: It is block scoped variable. It cannot be reclared or redefined. It is not hoisted, which means it cannot be used before its declaration. Hoisting means where variables and function declarations are moved to the top of their containing scope. This means that you can use variables and functions before they are declared in the code. However, only the declarations are hoisted, not the initializations. Example 1: console.log(x); // undefined var x = 5; console.log(x); // 5 In this case, the declaration of `x` is hoisted, but its initialization is not, so the first `console.log` outputs `undefined`. Example: function outerFunction(outerVariable) { return function innerFunction(innerVariable) { console.log('Outer Variable: ' + outerVariable); console.log('Inner Variable: ' + innerVariable); } } const newFunction = outerFunction('outside'); newFunction('inside'); // Output: // Outer Variable: outside // Inner Variable: inside A callback is a function which is passed as an argument to another function. This technique allows a function to call another function. A callback function can run after another function has finished. It can be synchronous or asynchronous. Example: (synchronous callback) function greet(name, callback) { console.log('Hello ' + name); callback(); } function sayGoodbye() { console.log('Goodbye!'); } greet('Alice', sayGoodbye); // Output: // Hello Alice // Goodbye! Example:(asynchronous callback - setTimeout) function fetchData(callback) { setTimeout(() => { const data = "Sample Data"; callback(data); }, 2000); } function displayData(data) { console.log("Data received: " + data); } fetchData(displayData); // After 2 seconds, it will log: Data received: Sample Data Example:(asynchronous callback - setInterval) function showTime() { const now = new Date(); console.log("Current Time: " + now.toLocaleTimeString()); } setInterval(showTime, 1000); // Calls showTime every second NOTE: setTimeout() => It is a predefined JS function that executes a function after a specified delay in milliseconds. setInterval() => It is a predefined JS function that repeatedly executes a function at specified intervals in milliseconds. Eg3: using arrow function ((name) => { console.log("Hello, " + name + "!"); })('Haritha'); // Output: Hello, Haritha! Promises are used to handle asynchronous operations in JavaScript. It has properties of state and result but we cannot access them directly, with the help of 3 states we can achieve it, Pending - here the result is undefined, Fulfilled - here the result has value, Rejected - here it has error object A promise is created using Promise constructor which takes in the callback function which has 2 parameters resolve and reject . Eg: const myPromise = new Promise((resolve, reject) => { const success = true; // Simulating a successful operation if (success) { resolve("Operation was successful!"); } else { reject("Operation failed."); } }); myPromise .then((message) => { console.log(message); // Output: Operation was successful! }) .catch((error) => { console.error(error); // Output: Operation failed. }); Async makes a function which returns a promise. Await makes a function which will wait for a promise. It can be used inside of async function only. Eg: function fetchData() { return new Promise((resolve) => { setTimeout(() => { resolve("Data fetched!"); }, 2000); }); } async function getData() { console.log("Fetching data..."); const data = await fetchData(); console.log(data); // Output: Data fetched! } getData(); // Output: // Fetching data... // (after 2 seconds) Data fetched!
