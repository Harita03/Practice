In JavaScript, object comparison returns true only when both variables reference the same object in memory. Otherwise, it returns false even if the object contents are identical. In JavaScript, constructor functions and classes are both used to create objects. Constructor functions are the older ES5 approach, while classes are a cleaner ES6 syntax. Internally, classes still use constructor functions and prototypes, but they make object creation and inheritance easier and more readable. Constructor (Old way): function Person(name) { this.name = name; } Class (Modern way): class Person { constructor(name) { this.name = name; } } NOTE: Internally, classes work using constructors To add a property to a constructor object using prototype in JavaScript, you attach that property to the constructor's prototype, not inside the constructor function itself. This makes the property shared by all objects created from that constructor. eg: Basic constructor: function Person(name, age) { this.name = name; this.age = age; } Adding property using prototype: syntax: ConstructorName.prototype.propertyName = value; eg: Person.prototype.country = "India"; Prototypal inheritance means one object can access properties and methods of another object via its prototype, allowing shared behavior without copying. Every JavaScript object has a hidden link to another object called its prototype. If a property is not found in the object itself, JavaScript looks up the prototype chain. PROTOTYPE CHAIN: child → parent → Object.prototype → null - JS checks child - If not found, checks parent - Then Object.prototype - Stops at null Object.freeze(): - It completely locks an object. - After freezing an object, - You cannot add new properties - You cannot delete existing properties - You cannot modify existing values - You cannot reconfigure properties - Object becomes fully immutable Object.seal(): - It partially locks an object. - After sealing an object, - You cannot add new properties - You cannot delete existing properties - You can modify existing property values - Object is sealed but editable Event Bubbling: Event Bubbling means the event starts from the target element and moves upward to its parent elements. Default behavior in JavaScript. Event Capturing: Event Capturing means the event starts from the top (window/document) and travels down to the target element. Generators in JavaScript are special functions defined using function* that can pause execution with the yield keyword and resume later. They return iterators and are useful for custom iteration, lazy evaluation, and \ managing complex flows. - Introduced in ES6 (ES2015) - Defined using function* syntax. - Uses the yield keyword syntax: function* myGenerator() {} yield keyword: - Pauses the generator function - Sends a value outside - Resumes from the same point next time Methods: 1. .next(value) => Moves to next yield 2. .return(value) => Stops generator completely 3. .throw(error) => Throws error inside generator NOTE: Before async/await , generators were used for asynchronouus flows.
